# DSA Mastery

Algorithmic problem solving in JavaScript and Python.  
Organized by pattern. Every solution with time and space complexity.

## Why Pattern-Based

Every DSA problem is a variation of one of 14 core patterns.
Learning the pattern means you can solve any problem that uses it —
not just the ones you have seen before.
